Case 5 — Driven Harmonic Oscillator

Potential: V(x) = x^2/2 + F*x (constant drive)

This script `case5.py` implements the exact displaced coherent-state solution for an initial
coherent Gaussian (ground-state width) and compares it with a Crank–Nicolson numerical solver.

Run:

python case5.py

Outputs: probability evolution, expectation values, convergence plots, and `animation.gif`.
