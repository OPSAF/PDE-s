Case 4 — Inverted Harmonic Oscillator

This folder contains `case4.py` which simulates the 1D TDSE with potential V(x) = -x^2/2
and compares the numerical split-step spectral solution with the analytic solution via the propagator.

Run:

python case4.py

Outputs: plots, convergence data and `animation.mp4` and `animation.gif`.
