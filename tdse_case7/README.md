Case 7 — 2D Coherent State in Isotropic Harmonic Oscillator

This folder contains `case7.py` which simulates a 2D coherent-state Gaussian wave packet
in the isotropic harmonic oscillator potential V(x,y)=0.5*(x^2+y^2). The analytic coherent-state
solution is compared with a 2D split-step spectral numerical solver.

Run:

python case7.py

Outputs: density maps, trajectory plot, `coherent_animation.gif`, `coherent_animation.mp4`, and `metrics.txt`.
