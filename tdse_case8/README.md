Case 8 — 2D Anisotropic Harmonic Oscillator

Potential: V(x,y) = 0.5*(wx^2 * x^2 + wy^2 * y^2)

This folder contains `case8.py` which implements analytic eigenstates for the anisotropic
harmonic oscillator (product of 1D Hermite functions with frequencies `wx` and `wy`), a
2D split-step spectral solver, error metrics, and visualization (density maps, contour plots, animations).

Run:

python case8.py

Outputs: `tdse_case8_outputs/` with frames, `animation.gif`, `animation.mp4`, and `metrics.txt`.
